# Changelog

All notable changes to RECON will be documented here.

## [1.0.0] - Unreleased

### Initial public release preparation

- Windows WPF desktop application for file scanning and organization planning.
- Rule-based file classification with confidence and move-risk information.
- Organization plan review and move preflight validation.
- Safe Commit workflow with SHA-256 verification.
- Persisted dry-run results and operation journal support.
- Desktop icon snapshot, identity mapping, and verification support.
- GitHub Actions workflow for publishing a self-contained Windows x64 executable.
